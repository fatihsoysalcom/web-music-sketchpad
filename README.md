# Web Music Sketchpad

This example demonstrates a basic web-based music sketchpad. Users can click on a grid to activate notes and then play them back using the Web Audio API with different instrument types and tempo.

## Language

`html`

## How to Run

Save the code as an HTML file (e.g., index.html) and open it in a web browser. Click on the grid cells to create notes, then click 'Play' to hear the melody.
